Network Settings

Base Hostname iDieser Name wird fuer mDNS und den Access Point genutzt. Die Device-ID wird automatisch angehaengt, damit mehrere Geraete im selben Netz eindeutig bleiben.
Data Output Mode iLegt fest, wie das Geraet seine Daten bereitstellt. Im normalen Betrieb ist meist HTTP (JSON, NMEA) richtig.
mDNS Device Discovery iWenn aktiv, ist das Geraet im lokalen Netzwerk zusaetzlich ueber seinen Hostnamen erreichbar, zum Beispiel boatmonitor-1.local.
MDS Settings
Uploads selected sensor groups to the configured Maritime Data Server when Wi-Fi is connected.
Enable MDS Upload iSendet Sensordaten nur bei aktiver WLAN-Verbindung an den Maritime Data Server. Zieladresse und API-Key muessen unten passend konfiguriert sein.
MDS Ingest URL iAus Sicherheitsgruenden werden MDS-Daten nur noch an HTTPS-Ziele gesendet. Die Server-Zertifikate werden gegen das eingebettete Root-CA-Bundle geprueft.
MDS API Key iDer API-Key wird beim Upload im JSON an board.apiKey gesendet. In den Geraete-Statusdaten wird er nicht mehr im Klartext zurueckgegeben.
MDS Sensor Groups iDiese Schalter aktivieren einzelne Datengruppen fuer den MDS-Upload. Es werden keine numerischen Sensor-IDs mehr verschickt, sondern sensorType und sensorName.
Send Battery Status (sensorType=ADC, v1=V, v2=capacity)
Send Tank Levels (sensorType=ADC, v1=t1%%, v2=t1adc, v3=t2%%, v4=t2adc)
Send Alarm and Relay Status (sensorType=Digital, v1=alarm, v2=relay, v3=temp1wire)
Send GPS Position (sensorType=GPS, v1=lat, v2=lon, v3=speed, v4=course)
Send Environment Data (sensorType=BME280, v1=temp, v2=hum, v3=press, v4=alt)
Send Dew Point (sensorType=BME280, v1=dewpoint)
Send VE.Direct Data (sensorType=DS2438, v1=V, v2=A, v3=temp)

LoRa Settings (ABP)

ABP credentials and radio behavior for LoRaWAN transmission.
LoRa Send Mode iBegrenzt, wann das Geraet aktiv per LoRa senden darf. Fuer den normalen Schlafbetrieb ist meist "Only in Standby" sinnvoll.
LoRa Device Address
LoRa Network Session Key
LoRa Application Session Key
Frequency Region
LoRa Channel Selection i0 bis 7 waehlen einen festen Kanal. Die dynamischen Optionen wechseln automatisch zwischen mehreren Kanaelen.
Fixed Spreading Factor
Dynamic Spreading Factor iWenn aktiv, passt das Geraet den Spreading Factor ueber mehrere Sendungen automatisch an. Das kann Reichweite verbessern, verlaengert aber teils die Airtime.
LoRa Send Interval iDer eingetragene Wert wird mit 60 Sekunden multipliziert. Beispiel: 10 bedeutet eine Sendung alle 10 Minuten.
Relay Behavior i"Control GPS Module" nutzt das Relais zum Ein- und Ausschalten des GPS-Moduls. "On" haelt das Relais dauerhaft aktiv.

Standby Mode Settings

Power-saving behavior while the device is waiting in standby.
Enable Standby Mode iIm Standby-Modus kann das Geraet schlafen und bei Alarmzustand wieder aufwachen. Der Alarm-Eingang X1-3 steuert dabei Wake und Sleep.
Standby Sleep Duration (minutes)
Keep Wi-Fi Active in Standby iWenn aktiv, bleibt WLAN auch im Standby verfuegbar. Das erhoeht den Stromverbrauch, ermoeglicht aber weiterhin Webzugriff und MDS-Uploads.

Calibration Settings

Curve coefficients and offsets used to convert ADC values into voltage and tank readings.
Battery Voltage Curve A2 iQuadratic calibration coefficient for the battery voltage input. Usually only changed when you use a custom calibration formula.
Battery Voltage Curve A1 iLinear calibration coefficient for the battery voltage input.
Battery Voltage Offset [V]
Tank 1 Curve A2 iQuadratic calibration coefficient for tank 1. Use this for non-linear tank geometries.
Tank 1 Curve A1 iLinear calibration coefficient for tank 1.
Tank 1 Offset [L]
Tank 2 Curve A2 iQuadratic calibration coefficient for tank 2. Use this for non-linear tank geometries.
Tank 2 Curve A1 iLinear calibration coefficient for tank 2.
Tank 2 Offset [L]
