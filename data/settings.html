Power and Standby

The Main Power Input mirrors the battery main switch. Switch on (12 V) keeps the device always on; switch off (0 V) allows sleep/wakeup operation when enabled below.
Sleep/Wakeup Mode iEnables automatic deep-sleep cycles while the battery main switch is off. The Main Power Input overrides this setting whenever 12 V is present and keeps the device always on.
Standby Sleep Duration (minutes)
Keep Wi-Fi in Standby iWhen enabled, Wi-Fi remains available during standby/wakeup operation. This increases power consumption, but allows web access and MDS uploads.

Calibration

Curve coefficients and offsets used to convert ADC values into voltage and tank readings.
Quick Battery Calibration

Use the helper below for a simple one-point correction. Measure the real battery voltage with a multimeter, enter that value, and the firmware will rebuild the battery curve as a safe linear mapping automatically.

This helper is meant for the analog battery input. If you use VEdirect-Read, the battery value comes from the external device and should not be calibrated here.

Advanced Battery Curve

The firmware calculates battery voltage with this formula:

Voltage = A2 * ADC * ADC + A1 * ADC + Offset

For the default linear setup, keep A2 = 0. Only change the coefficients manually if you deliberately want a custom curve.
