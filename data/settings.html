Calibration

Curve coefficients and offsets used to convert ADC values into voltage and tank readings.
Battery voltage curve

The firmware calculates battery voltage with this formula:

Voltage = A2 * ADC * ADC + A1 * ADC + Offset

For the default linear setup, keep A2 = 0. Then use two measured points from a multimeter and the displayed ADC raw value:

A1 = (Voltage2 - Voltage1) / (ADC2 - ADC1) Offset = Voltage1 - A1 * ADC1

Example workflow: measure battery voltage with a multimeter, note the matching ADC value from Sensor Values, repeat with a second voltage level, then calculate A1 and Offset. Use A2 only if the voltage divider or sensor is clearly non-linear.
